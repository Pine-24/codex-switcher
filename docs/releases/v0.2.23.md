# Codex Switcher Pine v0.2.23

Windows x64・Ubuntu x64向けの正式版です。未署名の手動インストール方式で、アプリ内自動更新は無効です。

## 修正内容

- Codex が WSL で動いていると、残り使用量の取得時にも `Cannot switch accounts while Codex processes are running in the selected WSL distribution` が出る問題を修正しました。未使用アカウントのトークン更新に不要な停止チェックを適用しません。
- 使用中アカウントは Codex 側の最新認証情報を読み直し、Codex 実行中や状態不明の間は共有トークンの更新を控えます。実際のアカウント切替時の停止確認は維持しています。
- 上部の状態表示を Codex App 本体の個数に変更しました。アプリ1個に複数の WSL バックエンドがあっても `1 Codex App running` と表示します。
- アプリが0個でも関連処理が残る場合は `Background activity running` と補足します。切替可否の判定には引き続き関連プロセス全体を使います。

## インストール

旧 Switcher をトレイも含めて終了してから更新してください。

- **Windows:** `Codex-Switcher-Pine_0.2.23_windows-x64-setup.exe` を実行します。WebView2 Runtime が必要です。
- **Ubuntu:** ダウンロード先で `sudo apt install ./Codex-Switcher-Pine_0.2.23_ubuntu-amd64.deb` を実行します。
- **Ubuntu AppImage:** `Codex-Switcher-Pine_0.2.23_ubuntu-amd64.AppImage` に実行権限を付けて起動します。

v0.2.22 および今回の `0.2.23-usage.*` テスト版と同じ Pine アプリ識別子・既存設定を使用します。
アカウントと設定の保存先は既存の `~/.codex-switcher` です。

## 署名・更新

Authenticode 署名・自動更新用署名はありません。上流版の更新 URL・公開鍵や自動更新用マニフェストは使用しません。
今後もこの fork の Release ページから手動更新してください。添付の `SHA256SUMS.txt` で配布物を照合できます。
