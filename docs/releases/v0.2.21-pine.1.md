## Windows x64 / Pine fork 初回 Pre-release

Windows 11向けの手動インストール版です。Intel/AMDの64bit Windowsを対象とし、ARM64ネイティブ版ではありません。

**インストールするファイル:** `Codex-Switcher-Pine_0.2.21-pine.1_windows-x64-setup.exe`

### 修正内容

PR #1でマージしたWindows managed Codex app-server対応を含みます。画面のない共有サーバーを検出し、確認付きの終了操作で停止させ、認証ファイルの切り替え直前にもプロセスを再確認します。修正本体は `e69e4260e22d2b8336d682e432e6795ccefa2368` と同じです。タグには、版番号・Forkのインストーラー識別子・配布設定のみを調整した、実際のビルド対象ソースを保存しています。

### 導入

既存のCodex Switcherをトレイから終了してから、このインストーラーを実行してください。アプリ名は **Codex Switcher Pine** です。上流版を自動でアンインストール・上書きしない、別のインストーラー識別子を使用しています。

アカウントの保存先は既存の `~/.codex-switcher` のままです。上流版とFork版を同時に起動しないでください。導入前のバックアップは手元に安全に保管し、認証情報やトークンをGitHubやチャットへ投稿しないでください。

### 署名・更新

この初回版にはAuthenticode署名がありません。Windows SmartScreenで未認識アプリの警告が出る場合があります。配布元とファイル名を確認し、添付の `SHA256SUMS.txt` と照合してください。OSの保護機能を全体で無効にする必要はありません。

上流版の更新URL・署名鍵は使用せず、アプリ内自動更新は無効です。次のFork版への更新もReleaseページから手動で行います。WebView2 Runtimeが必要です。

### 検証範囲

公開ワークフローは、Windowsランナー上のフロントエンドテスト、Rustテスト、NSISリリースビルド、x64実行ファイルの形式確認、サイレントインストール、インストール済み実行ファイルのハッシュ照合、10秒間の起動継続確認が成功した場合のみ、このPre-releaseを公開します。実際のランナーOS・ビルド元コミット・実行URLは `BUILD-INFO.json` に記録しています。

**GitHubのWindowsランナーでの確認と、ユーザーのWindows 11実機での確認は別です。実アカウントのログイン・切り替え、実際のCodex共有サーバーの停止は未検証です。** 初回版としてPre-releaseにしています。

明示的な `--managed-daemon` のない旧形式、keyring認証、別CODEX_HOMEは今回の修正対象外または自動停止を拒否する場合があります。Warm-upや利用上限の仕組みを変更するものではありません。
