# Codex Switcher Pine v0.2.22

Windows x64・Ubuntu x64向けの正式版です。未署名の手動インストール方式で、アプリ内自動更新は無効です。

## 修正内容

- PR #2を含みます。Windows・WSL・Ubuntuの認証フォルダーを検出し、候補が食い違う場合は切替前に選択を求めます。
- WindowsアプリがWSLのCodexを使う構成に対応します。Switcherの`CODEX_HOME`だけを優先してWSL検出を飛ばす問題を修正しました。
- 選択した保存先を保持し、確認付きのWSL Codex終了と切替に使用します。
- Ubuntuの画面を持たないCodexプロセスの検出、同じActiveアカウントの再適用にも対応します。

## インストール

- **Windows:** `Codex-Switcher-Pine_0.2.22_windows-x64-setup.exe`を実行してください。WebView2 Runtimeが必要です。
- **Ubuntu:** `Codex-Switcher-Pine_0.2.22_ubuntu-amd64.deb`をダウンロードし、保存先で`sudo apt install ./Codex-Switcher-Pine_0.2.22_ubuntu-amd64.deb`を実行してください。
- **Ubuntu AppImage:** `.AppImage`に実行権限を付けて起動できます。Ubuntu 22.04でビルドしています。

先に旧Switcherをトレイも含めて終了してください。正式版のアプリ名は **Codex Switcher Pine** です。
WindowsのPine版識別子は旧Pine版と同じで、上流版・今回のテスト版とは別です。テスト版が残っていても同時起動しないでください。
アカウントと設定は既存の`~/.codex-switcher`を使用します。認証情報はReleaseやチャットへ投稿しないでください。

WindowsからWSLのCodexを使う場合、SettingsでWSL側の候補を選択してください。
終了確認に同意するとWindowsアプリやチャットも切断される可能性があります。
再起動後は、SwitcherのActive表示だけでなくCodex自身のアカウント表示を確認してください。

## 署名・更新

Authenticode署名・自動更新用署名はありません。上流版の更新URL・公開鍵は使用せず、自動更新用マニフェストも配布しません。
今後の更新はこのforkのReleaseページから手動で行ってください。
Windowsで未認識アプリの警告が出る場合があります。配布元と添付`SHA256SUMS.txt`を確認してください。OSの保護機能を全体で無効にする必要はありません。

## 検証範囲

PR #2の全8チェック成功後、確認用`0.2.22-pine.pr2.2`でユーザーからWindows/WSL構成の切替成功報告を受けています。
正式版は同じ修正を含むマージ済みmainを基に、版番号・Pine配布設定とリリース検証を調整して再ビルドします。
公開前に両OSのテスト・ビルド、Windowsのサイレントインストール・実行ファイル照合・10秒起動、Ubuntuパッケージ情報を検証します。
各OSの`BUILD-INFO`にビルド元コミットと実行URLを記録します。

正式版バイナリでの実アカウント切替とUbuntu実機動作は未確認です。keyring認証は対象外です。
